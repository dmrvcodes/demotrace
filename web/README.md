# DemoTrace web

The Next.js frontend for DemoTrace. It currently runs in local fixture mode; no AWS service or model inference is called by this app.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and choose **Try with sample**.

## Sample media attribution

`public/samples/demotrace-sample.mp4` starts with a DemoTrace promise slide authored for this project, followed by an excerpt of **Big Buck Bunny** by the Blender Foundation, used under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
